### projects

**[jetson-inference](https://github.com/amadeobonde/jetson-inference)** — LLM inference engine that streams quantized weights off NVMe directly to GPU using `io_uring`. Built for Jetson Orin Nano (8GB). Custom CUDA kernels + sparse FFN with activation prediction cuts I/O ~60%.
`C++` `CUDA` `io_uring` `Q4/Q8 quant`

**[HerbLens](https://github.com/amadeobonde/HerbLens)** — iOS plant identification app. Point camera → instant ID + care guide + AI chat. SwiftUI frontend, Supabase backend, Deno edge functions, Gemini vision + Claude for chat.
`Swift` `SwiftUI` `Supabase` `Gemini` `Claude API`

**[anthropic-kernel-challenge](https://github.com/amadeobonde/anthropic-kernel-challenge)** — Optimized a custom VLIW SIMD instruction scheduler to 1,358 cycles. Beat Claude Opus 4.5's best score (1,363). DAG scheduling, WAR hazard elimination, vectorized SIMD batching.
`Python` `VLIW` `compiler internals`

**[devexana-reels](https://github.com/amadeobonde/devexana-reels)** — Automated short-form content engine. Generates 6 video formats (viral, meme, Reddit, iMessage, leaderboard, moody montage), quality-gates them, sends to Telegram for one-tap review.
`Python` `MoviePy` `Remotion` `Gemini API` `Telegram Bot`
